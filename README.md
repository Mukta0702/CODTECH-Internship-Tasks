# CODTECH-Internship-Tasks

Completed tasks for the **CODTECH IT Solutions Internship**.

## 📌 Overview
This repository brings together internship projects across **computer vision, NLP, supervised learning, and recommendation systems**. Each notebook demonstrates a different applied machine learning workflow.

## 🧠 Tasks
- `task1.ipynb` - CNN for image classification using TensorFlow/Keras
- `task2.ipynb` - NLP sentiment analysis using TF-IDF and Logistic Regression
- `task3.ipynb` - Decision Tree classifier with feature importance analysis
- `task4.ipynb` - Recommendation engine using similarity-based recommendations

## 🛠 Skills Demonstrated
- Data preprocessing and feature engineering
- Supervised machine learning workflows
- Model training and evaluation
- NLP pipeline development
- Recommendation system fundamentals
- Notebook-based experimentation and reporting

## 🎯 Purpose
This repository serves as a collection of internship deliverables and shows hands-on work across multiple machine learning problem types.
